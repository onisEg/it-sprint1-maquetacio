# TheBox — Adaptive & Accessible Layout

Vanilla HTML and CSS implementation of a landing page design,
built responsive and accessible as part of IT Academy Sprint 1.

## Technologies
- Semantic HTML5
- CSS Grid & Flexbox
- CSS custom properties & clamp() for fluid design
- Mobile-first methodology

## Run
Open `index.html` in a browser, or use a live server.
